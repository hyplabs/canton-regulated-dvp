# Documentation

Use these paths depending on what you are trying to do.

## Learn The Code

- [Daml learning guide](learning/daml-learning-guide.md) teaches the language
  through the V1 workflow and completed DvP model.
- [V1 regulated-settlement architecture](architecture/regulated-settlement-v1.md)
  explains the intentionally simple evidence-based state machine.
- [Tokenized DvP architecture](architecture/tokenized-dvp.md) explains both
  Token Standard allocation legs and atomic execution.
- [Stakeholder application](architecture/stakeholder-ui.md) maps browser actions
  to Ledger, wallet, and registry APIs.

## Run And Present

- [Local runbook](demo/runbook.md) covers prerequisites, tests, Quickstart, and
  troubleshooting.
- [Presenter guide](demo/demo-guide.md) provides the browser and terminal
  walkthroughs.
- [Historical LocalNet rehearsal](demo/historical-localnet-rehearsal.md) records
  the earlier one-leg runtime evidence and clearly marks its scope.

## Research

- [Canton research brief](research/canton-research-brief.md) summarizes the
  builder path, practical stack, and official upstream sources.

## Project Notes

The `project-notes/` directory preserves decisions, delivery milestones,
readiness checks, and scope changes. These documents explain how the proof of
concept evolved; they are not the primary setup or presentation instructions.
